## #  SQLMate

##  1. When to Use
When you need to write a SQL query to retrieve data but are unsure how to write it or where to start.
When you are unsure about the underlying data logic needed to get the results.

##  2. Why Use This?
Optimized SQL Output: Generates efficient SQL queries with minimal run time that you can use immediately.
Detailed Explanations: Breaks down the query line-by-line so you understand exactly what it is doing.
Important Reminders: Alerts you to potential data caveats and edge cases (e.g., noting that total user counts across different website pages might overlap).
Mini Classroom: Concludes with short descriptions of key SQL functions and concepts used (e.g., explaining what is GROUP BY).

##  3. If You Are...
SQL learners and students.
Professionals and students who need to use SQL regularly for work or school.

##  4. How to Install
Download this file.
Install it into your AI agent.
##  5. How to Use
Upload your schema details (field/column names, database introduction, or tables) to the AI agent.
Describe what data or statistics you want to retrieve in plain language.
